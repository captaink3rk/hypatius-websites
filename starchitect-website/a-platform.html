02 · Architecture

A reactive backbone, 100% FOSS.

Every node runs the full operational stack on a K3s mesh with NATS JetStream as the reactive backbone — the Orbital Edge Bus. Postgres holds state, Orekit drives astrodynamics, Qdrant powers vector correlation. Nothing proprietary in the critical path; nothing that ties you to a vendor.

The architecture scales without a rewrite: from a $200 Raspberry Pi cluster on a homelab bench to a national-scale constellation mesh, allied-nation nodes plug in through the same interface.

Frontend

React + CesiumJS — real-time 3D orbital visualization and the unified Astro UX.

Bus

NATS JetStream — the Orbital Edge Bus. Reactive, replayable, survivable messaging.

Compute

K3s mesh + mdao-worker. Trajectory optimization via Dymos / OpenMDAO (IPOPT).

State

PostgreSQL + Qdrant. CRDT merge for zero-data-loss reconciliation across degradation.

SDOL & SMPDL

SDOL — the Space Domain Operations Language — is the human-facing DSL operators write in. It compiles to SMPDL, the Starchitect Maneuver Plan Description Language, a JSON contract the optimization workers consume. The same plan that wargamed yesterday commands live hardware tomorrow.

02 · The Ladder

Five tiers of graceful degradation.

From full mesh to client-only — each tier holds the mission with progressively fewer nodes, never losing cryptographic assurance.

Cryptographic assurance · held at every tier
T0Full mesh
T1Reduced
T2Island
T3Single node
T4Client-only

T0 · Full mesh. All nodes nominal. Primary path active across the constellation.

T1 · Reduced. A ground node is lost. Traffic re-routes to the alternate tier and the mission holds.

T2 · Island. Surviving nodes operate autonomously. No cloud tether required.

T3 · Single node. One node carries the mission. The local-first stack stays operational.

T4 · Client-only. The mission continues on the operator's own client until a node returns. On reconnection, CRDT merge reconciles state with zero data loss.

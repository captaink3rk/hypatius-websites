# craton-hero-2400.jpg — for craton-erp.us, not for this deploy folder

**2400×1000 (12:5) · progressive JPEG · Slot 02 of the image prompt pack**

This is the only one of the twelve renders that does **not** belong to hypati.us. It is the page
hero for **craton-erp.us**, behind *"Nothing to see here. Exactly."* — a single bronze-lit stratum
boundary running edge to edge, the layer above reading as mass and the layer below as compacted dark.

It ships loose, outside `hypatius-website/`, because craton-erp.us deploys from a path that is not in
this package — and, as of this build, from no project on the HYPATIUS Vercel team that I could find.
Whoever owns that deploy drops this file into CRATON's own image directory.

## Two things to carry across when you place it

1. **CRATON's site is cached the same way.** If its `/site/` or `/assets/` directory carries a
   one-year immutable header the way hypati.us does, do not overwrite whatever hero is there now.
   Ship this under a new filename and update the reference.
2. **The veil belongs over the left.** The seam runs the full width and the rock above it is busy.
   The page's headline needs roughly the left half returned to a flat dark before type goes on it —
   the same treatment `.plat--left .plat__veil` gives on hypati.us: a 90° linear gradient from
   `rgba(4,9,15,0.94)` at 0% through `0.7` at 42% to `0.22` at 100%.

## Why this image and not a launch

CRATON is DCAA-ready timekeeping, charge codes, indirect rate pools and the SF 1408 binder. The page's
joke is that compliance becomes uneventful, so the image is the straight man: something that has not
moved in a very long time and is not going to. A craton *is* stable continental bedrock — the name was
the brief. Bronze seams only; gold belongs to STARCHITECT.

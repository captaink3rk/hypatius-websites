Questions we get asked

The short answers.

Is the binder a document or a screen?
A screen that exports. It is evaluated on read, so there is no version of it that is out of date while looking current.
Can we edit an area's state before a review?
No. There is no manual override. An area changes state when the underlying rows change, which is the only reason the binder is worth showing an auditor.
Does passing all fourteen areas here mean we pass the survey?
No, and we will not say it does. The survey is conducted by a person against your actual system. The binder means you can answer every question with rows instead of recollection.
What does the export contain?
The fourteen areas, their current state, the reason for any area in attention, and the query behind each one. Format and schema are in the API contract for engineering.

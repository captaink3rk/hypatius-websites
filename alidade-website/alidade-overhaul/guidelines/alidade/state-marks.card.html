Brand · added v2

State is never colour alone.

v1 carried the win bands on teal, gold and coral with no structural backup. That is invisible to roughly one in twelve men, to forced-colors mode, to a greyscale print of a deck, and to a screen read in sunlight through polarised lenses — which is the actual reading condition for a capture lead checking a gate in a parking lot. Every stateful component now carries a mark and a word. Colour is the third channel, never the first.

The vocabulary is not new. These are the Unicode geometric marks the brand already uses in mono status contexts — v2 only makes them load-bearing.

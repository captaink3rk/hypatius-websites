The scoring instrument

Seven factors. Every one cited.

Seven weighted signals resolve into one probability of win — with the gaps named, so a go/no-go is defensible to the person who has to fund it. The colour is calculated from the score, never chosen. The band carries a mark and a word as well as a hue, so it survives a greyscale print and a colour-deficient reader.

80+
Pursue

Commit the capture team. Gaps, if any, are closeable inside the schedule.

60–79
Consider

Bid only with a partner who closes the named gap. Teaming changes the answer.

<60
Hold

The B&P is better spent elsewhere. The score says why, in writing.

Governance

Secure by design. Collaborative by architecture.

Contested capture runs on trust. Tenant isolation, an append-only audit record, the consent ledger, and forensic watermarking are not features bolted on for procurement — they are the architecture.

01 · Isolation

Tenant isolation

Row-level security per tenant, enforced in the database. Your data never co-mingles with another prime's.

02 · Record

Append-only audit

Every call recorded with inputs, tools called, outputs, and citations. Denials recorded too. Exportable for the file.

03 · Consent

Scoped grants

Tool groups, fields, and expiry per grantee. Teaming requests reveal identity only on mutual consent.

04 · Authority

Designated approvers

The agent proposes; a person disposes. Read-only tools run automatically. Anything that acts pauses for approval.

05 · Provenance

Forensic watermarking

Persists on drafts and on final exports. Unwatermarked export is gated by tenant policy.

06 · Routing

Provider routing

Model and region routing under tenant control, with security checks in the build pipeline.
